# Dad Joke Generator 😄

A fun web application that generates random dad jokes using an external API. Built for laughs!

## ✨ Features

- **Random Jokes** - Get a new dad joke with each click
- **Simple UI** - Clean, minimalist design
- **API Integration** - Fetches jokes from external API
- **Responsive** - Works on all devices

## 🛠️ Tech Stack

- HTML/CSS/JavaScript
- Dad Jokes API

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Sukrit3007/Dad-joke-Generator.git

# Open index.html in your browser
```
